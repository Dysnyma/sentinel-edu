# 文本纠错对比视图

## ADDED Requirements

### Requirement: 纠错前后双栏对比
文本纠错完成后，系统 SHALL 显示一个可折叠的对比区域，展示每条文本纠错前后的差异。

- 对比视图使用 `st.columns(2)` 左右排列：左侧"原文"，右侧"纠错后"。
- 差异部分使用颜色高亮：删除内容用红色背景（`#ffcccc`），新增内容用绿色背景（`#ccffcc`）。
- 每条对比结果使用 `st.container` 包裹，之间用分割线隔开。
- 对比区域默认折叠，用户点击展开查看。

#### Scenario: 纠错完成后显示对比
- **WHEN** 用户点击"大模型纠错"按钮并成功完成纠错
- **THEN** 在进度条下方出现一个可折叠的"📊 纠错前后对比"区域
- **THEN** 展开后逐条对比原文与纠错后的文本

#### Scenario: 无差异时
- **WHEN** 原文与纠错后文本完全一致
- **THEN** 仍显示该条对比，标注"无改动"
